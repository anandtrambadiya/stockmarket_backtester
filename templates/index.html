The edge explained
Why earnings drift works.

After a genuine earnings beat, institutional funds take 10–15 days to fully reposition. They can't buy instantly — size limits, internal approvals, index rebalancing. Retail gets in first. ML identifies which gap-ups have the strongest institutional follow-through signal.

The baseline (buy all earnings gap-ups in bull markets) earns +0.56%/trade. The ML filter takes only the top 25%, pushing it to +1.05%/trade with far lower drawdown.

Design decisions
Built to be honest
Walk-forward cross-validation
TimeSeriesSplit with 5 folds — training always precedes testing chronologically. Zero future leakage.
Regression, not classification
Predicts 10-day forward return magnitude, then ranks. Avoids the 50% accuracy trap of daily direction prediction.
Long-only, 6% hard stop
No shorting. No leverage. Entry at next-day open. 0.1% brokerage (Zerodha). Realistic execution constraints.
Bear market filter
Nifty 500 50-day trend < 0 → no trade. Earnings drift requires institutional buying. Bear markets invert the signal.
