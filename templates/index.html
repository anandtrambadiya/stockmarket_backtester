Design decisions
Built to be honest
No look-ahead bias
Strict chronological 80/20 split. The model never sees a single test-period data point during training.
Balanced class weights
class_weight='balanced' corrects for any up/down day imbalance in training data.
Multiplicative compounding
Returns compound daily — same method as the benchmark — for a mathematically fair comparison.
Daily cache layer
Pipeline output cached to JSON. Re-runs only when the calendar date changes. Zero redundant API calls.
